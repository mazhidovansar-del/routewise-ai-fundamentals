# AI Usage Declaration

**Project:** RescueGrid — AI-assisted community food rescue

Generative AI tools were used to help develop the project concept, draft explanatory text, scaffold and refine the prototype interface and algorithm implementation, and prepare the report, presentation, and demo narration. The interface was also refined using the Impeccable and taste-skill frontend guidelines requested for this project. All algorithm behavior described in these materials is implemented in the included JavaScript source code. The sample listings, hub capacities, demand figures, and locations are synthetic demonstration data created for this project; they are not collected from real organizations or people.

The team is responsible for reviewing, understanding, testing, and presenting the work. No external AI service is called by the running application. The system does not make food-safety determinations and must not be used to distribute food without human verification.
