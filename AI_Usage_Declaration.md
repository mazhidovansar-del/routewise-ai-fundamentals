# AI Usage Declaration

**Project:** RouteWise — courier order and route planner

Generative AI tools were used to help refine the project concept, draft explanatory text, scaffold and refine the prototype interface and algorithm implementation, and prepare the report, presentation, and demo narration. The interface was also refined using the Impeccable and taste-skill frontend guidelines requested for this project. Algorithm behavior described in the materials should be checked against the included JavaScript source before submission. The city map, orders, and travel estimates are synthetic demonstration data, not live location or traffic data.

The submitting team is responsible for reviewing, understanding, testing, and presenting the work. The running application does not call an external AI service. It is a planning prototype and should not be represented as a live courier dispatch or navigation service.
