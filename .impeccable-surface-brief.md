# Courier dispatch surface

## Direction contract

**THESIS:** A courier should see the city and the work together. A sequence is only useful when the travel and cooking wait behind it are legible.

**OWN-WORLD:** Map-first dispatch console. Quiet road neutrals, clear green route, orange restaurant markers, blue customer markers, and a dark courier marker. Standard web map controls and restrained work surfaces; map geometry is the signature visual move.

**STORY:** Set the courier start, assign each restaurant and customer, enter remaining ready times, then generate and inspect a feasible sequence.

**FIRST VIEWPORT:** On desktop, fixed header, concise task heading and one action. Main screen is a large interactive city map beside a compact order queue; clear selection target and map legend sit directly above the map. On mobile, the same controls stack in order: action and instructions, location map, courier start, order queue, route plan.

**FORM:** Map clicks and labeled selects stay synchronized. Readiness is shown as time remaining from plan start and is recalculated at each arrival. Invalid location pairs and shift-limit failures receive a plain recovery message.

**MOTION:** A restrained route trace draws only after planning. Selection, focus, active markers, and completion states change immediately. Reduced-motion users receive a static highlighted route.
