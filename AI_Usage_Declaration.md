# AI Usage Declaration

**Project:** RouteWise — courier pickup and delivery route planner

Generative AI assisted with developing the project concept, drafting and refining application code and interface copy, preparing synthetic visual assets, and drafting the technical report and presentation. AI was also used to review the relationship between the implementation and the course-project requirements.

The submitted team must review and understand the code and written materials and should revise this declaration if its actual use of AI tools differs from the description above. No external AI service is called by the running application. RouteWise uses a fixed synthetic map, sample orders, and estimated travel times; it does not process live customer or courier data.
